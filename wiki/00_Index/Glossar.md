# Glossar

Begriffe aus dem Mitarbeiterhandbuch, mit Verweis auf das jeweilige Kapitel.

| Begriff | Bedeutung | Kapitel |
|---|---|---|
| Neukundenzettel | Formular, das Neukund:innen beim Empfang ausfüllen | MH-01 |
| Frisurenmappe | Mappe mit Frisurenbeispielen (Lesezeichen in zwei Farben: gefällt/gefällt nicht) | MH-01, MH-06 |
| Kundenlaufzettel | Zettel nach der Haarwäsche mit allen eingetragenen Dienstleistungen | MH-04 |
| Karteikarte | Kundenkarte für Farb-/Behandlungsdaten (Stamm- und Neugäste) | MH-10 |
| W-Fragen | Standardfragen im Beratungsgespräch zu Schnitt/Frisur (Was stört Sie, was hätten Sie gerne …) | MH-03 |
| Limbic Check | Auftreten über Duft, Sprache, Körpersprache, Mimik | MH-19 |
| NK-Vermerk | Kürzel „NK" im Terminblock für Neukund:innen | MH-12 |
| Terminblock | Terminplan/-buch, in dem Reservierungen eingetragen werden | MH-12, MH-13 |
| Salonleitung | Rolle, die bei schwereren Reklamationen hinzugezogen wird | MH-16 |
| SP-Deep Cleanser | Produkt für die Haarwäsche vor der Dauerwelle | MH-11 |
